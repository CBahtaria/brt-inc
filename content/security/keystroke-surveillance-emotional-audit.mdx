Keystroke dynamics — the temporal pattern of how you type — have been studied for identity authentication since the 1980s. The same signal that can verify who you are can also reveal how you feel. This is not a future capability. The raw data is generated by every keyboard attached to every computer, and browsers expose it at millisecond precision by default.

## The Signal: Inter-Key Interval Analysis

The primary features extracted from keystroke dynamics are dwell time (how long a key is held) and flight time (the interval between releasing one key and pressing the next). These values are stable across sessions for a given individual typing familiar material, but they shift measurably with cognitive and emotional state.

Research across multiple institutions has established correlations between altered keystroke timing and elevated stress, anxiety, and fatigue. The mechanism is physiological: emotional state modulates the autonomic nervous system, which affects fine motor control, including the timing precision of finger movements. A person under sustained work stress types differently than a baseline — slightly slower, with more variability in inter-key intervals, and with more correction events (backspace, retype).

The critical characteristic for surveillance purposes is that these patterns are stable enough to build a personalised baseline over weeks and sensitive enough to detect deviations from that baseline. A monitoring system does not need to know the absolute emotional state of a user; it needs to detect anomalous deviation from that individual's established pattern, which requires only a few weeks of background data collection.

## Browser Exposure: Millisecond Timestamps by Default

The JavaScript `KeyboardEvent` interface exposes `timeStamp` at millisecond precision by default in all major browsers. `keydown` and `keyup` events fire separately, allowing flight time computation without any privileged access. A web application — any web application — running in a browser tab can log these timestamps continuously while the tab has focus.

Browser vendors have incrementally coarsened timer resolution to mitigate high-precision timing attacks. `performance.now()` has been limited to 100 microsecond resolution in some configurations. But the coarsening applied to high-frequency timing APIs has not uniformly propagated to `KeyboardEvent.timeStamp` across all browsers and configurations. Where millisecond resolution survives, the inter-key interval measurements needed for emotion inference remain viable.

This is the threat model for government systems and enterprise environments: employees working in web-based applications — government portals, HR systems, document management tools — are continuously generating keystroke timing data accessible to the application layer. If the application or an injected script is collecting that data, a longitudinal emotional profile is being built without the user's knowledge.

## The Whistleblower Risk

The insider-threat monitoring use case is where this capability becomes most concerning for institutional security. Organisations deploying employee monitoring software — commercially available products in this category include Teramind, Veriato, and similar tools — can configure keystroke dynamics collection as a continuous background process.

The adversarial framing: an employee who begins researching whistleblower protection, preparing documentation of malfeasance, or contacting journalists will exhibit measurable changes in their keystroke pattern relative to their baseline — elevated anxiety producing distinctive timing deviations. A sufficiently sophisticated monitoring system correlates those deviations with the content of typed text (also logged) and the timing of application focus events (also logged). The employee has not acted overtly. The system has already flagged the anomaly.

In government environments in SADC where whistleblower protection legislation is limited or unenforced, this capability in the hands of an institutional IT administrator represents a structural threat to protected disclosure.

## Countermeasure: Timestamp Coarsening at the Browser Layer

The effective mitigation does not require disabling keyboard input. It requires destroying the timing resolution of inter-key interval measurements while preserving functional typing.

A browser extension that intercepts `KeyboardEvent` objects and rounds `timeStamp` values to 50-millisecond buckets — before those events reach application JavaScript — eliminates the inter-key interval information needed for emotion inference. Flight times are typically 50–200ms for comfortable typing; rounding to 50ms buckets reduces the number of distinguishable bins to four or fewer, destroying the feature space that emotional models operate on. Dwell time precision is similarly degraded.

Fifty milliseconds is below the threshold of human perceptual sensitivity to typing latency. The intervention is transparent to the user and to legitimate application functionality. The privacy benefit is categorical: the surveillance modality is eliminated, not reduced.

For institutional hardening in SADC government environments, the deployment approach is a centrally managed browser extension enforced through group policy, applied to all user sessions on managed devices. The extension requires no server-side infrastructure and imposes no performance cost.
